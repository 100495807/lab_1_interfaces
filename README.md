# lab_1_interfaces

Practica de Interfaces de Usuario centrada en el desarrollo de una web estatica tematica sobre Papa Noel. El proyecto trabaja estructura HTML, estilos CSS, navegacion entre paginas, recursos visuales y una experiencia sencilla orientada a usuario final.

## Objetivo

Construir una interfaz web multipagina aplicando conceptos basicos de diseno, maquetacion, navegacion, formularios y uso de imagenes.

## Tecnologias

- HTML
- CSS
- Recursos graficos locales
- Diseno responsive basico

## Paginas Principales

| Archivo | Descripcion |
| --- | --- |
| `index.html` | Pagina principal / home. |
| `papa_noel.html` | Seccion tematica sobre Papa Noel. |
| `cartas.html` | Pagina de cartas. |
| `enviar.html` | Pagina para enviar carta. |
| `jugar.html` | Pagina de juego/interaccion. |
| `todo_junto.html` | Version integrada del contenido. |
| `style.css` | Estilos globales de la web. |
| `imagenes/` | Assets usados en la interfaz. |

## Como Verlo

Abrir `index.html` directamente en el navegador:

```text
index.html
```

No requiere servidor ni instalacion de dependencias.

## Aprendizajes

- Crear una estructura de navegacion entre paginas HTML.
- Separar contenido y presentacion mediante CSS.
- Usar imagenes y recursos locales en una web estatica.
- Diseñar formularios y secciones visuales para usuario final.
- Documentar el uso de IA en apoyo al desarrollo en `leame.txt`.

## Estado

Proyecto academico finalizado. Se conserva como practica inicial de diseno de interfaces web.
